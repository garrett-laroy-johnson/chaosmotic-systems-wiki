Chaosmotic Systems Wiki Editor

This collaborative knowledge platform allows you to contribute to the class wiki. All changes are automatically saved to the public repository and published to the live site.

Getting Started

  1. Browse Articles: Use the sidebar to view existing articles
  2. Edit Content: Click any article to open the editor
  3. Save Changes: Click "Save" to commit your edits to GitHub
  4. Create Articles: Use wiki links [[Article Name]] to create new pages
  5. View Live Site: Click "Live Site" to see the published wiki

Wiki Link Syntax

Create connections between articles using double brackets:

[[Cybernetics]] → Links to cybernetics.md (creates file if needed)
[[Norbert Wiener|the founder]] → Links to norbert-wiener.md, displays "the founder"

Markdown Formatting

# Heading 1 Main section headers
**bold text** Emphasis
*italic text* Secondary emphasis
- List item Bullet points

Publishing Workflow

Changes follow this automatic process:

1. Edit → Save
→
2. Sync to GitHub
→
3. Auto-build
→
4. Live Site Update

Updates typically appear on the live site within 2-3 minutes.

Navigation

  • Sync: Manual repository sync (usually automatic)
  • Publish: Bulk commit multiple changes
  • Live Site: View the published wiki
  • Preview: See rendered markdown while editing
